# 改動說明文件

## Docs 資料夾用途
- 專門存放專案相關的說明文件與技術文檔
- 方便日常開發時快速查閱與維護
- 與程式碼分離，保持專案結構清晰

## 建立原因
- 作為日常開發習慣，集中管理文檔
- 減少散落在不同地方的說明，提升可維護性
- 提供團隊成員一致的文件存放位置

## 使用方式
- 所有技術流程、API 說明、測試紀錄、臨時備忘等，統一放在 `Docs/`
- 檔案命名依照個人習慣即可，例如：
  - `Docs/api_notes.md` → API 草稿或備忘
  - `Docs/log_usage.md` → 日誌相關說明
  - `Docs/random.md` → 零散筆記
  - `Docs/ideas.md` → 開發靈感或 TODO
